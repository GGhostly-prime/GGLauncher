GGLauncher — сборка EXE без установки Python на вашем компьютере

ВАЖНО:
- Сам GGLauncher.exe будет работать без установленного Python.
- Python используется только на серверах GitHub для сборки EXE.
- Нужен аккаунт GitHub и загрузка этой папки в новый репозиторий.

КАК ПОЛУЧИТЬ EXE:
1. Создайте аккаунт на https://github.com/ (если его ещё нет).
2. Создайте новый репозиторий, например GGLauncher.
3. Распакуйте архив и загрузите ВСЕ его файлы и папки в репозиторий.
   Важно: папка .github должна попасть в корень репозитория.
4. Откройте вкладку Actions в репозитории.
5. Выберите workflow "Build GGLauncher for Windows".
6. Нажмите Run workflow и подтвердите запуск.
7. Дождитесь зелёной галочки (обычно несколько минут).
8. Откройте завершённый запуск workflow и скачайте артефакт
   GGLauncher-Windows внизу страницы.
9. Распакуйте скачанный архив — внутри будет GGLauncher.exe.
10. Запускайте GGLauncher.exe двойным нажатием.

Примечания:
- Это сборка текущего исходного кода, а не гарантия, что все функции уже готовы.
- Вход Microsoft пока требует Client ID: в gglauncher.py замените
  PASTE_YOUR_MICROSOFT_CLIENT_ID_HERE на Client ID своего приложения.
  Если изменить исходник, workflow нужно запустить повторно.
- Для запуска Minecraft также требуется Java подходящей версии.
- Не скачивайте и не запускайте EXE из неизвестных репозиториев.
